Questions and Answers

How many images can I batch resize simultaneously?
You can select up to 50 images in one batch. The tool processes them sequentially using HTML5 Canvas Web APIs and packages them into a clean ZIP archive.
Will batch resizing distort or stretch my photos?
Never. When you specify a maximum width (e.g. 1920px), Vytra scales the height proportionally to maintain the exact original aspect ratio for every single photo.
Why should I convert my images to WebP during batch resizing?
WebP is Google's modern image format that delivers 30% to 50% smaller file sizes than JPG at the same visual quality. Websites using WebP load faster, rank higher on Google Core Web Vitals, and consume less mobile data for visitors.
Are my bulk photos stored or cached on any server?
Never. All resizing, compression, and ZIP bundling happen 100% locally in your device's web browser RAM. Your files never touch any external server.
