Password Security FAQ

How are these passwords generated?

We use the modern browser Web Crypto API (window.crypto.getRandomValues), which generates cryptographically secure pseudorandom numbers resistant to prediction.

Are generated passwords saved anywhere?

Never. All generation happens strictly in your browser memory and is erased immediately when you close the tab.
