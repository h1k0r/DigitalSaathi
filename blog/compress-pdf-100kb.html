How to Compress a PDF to Under 100KB Without Losing Readability

Last updated: 27 October 2026 · By h1k0r · Category: PDF Guides

Government exam portals, scholarship forms and job applications rarely accept a PDF bigger than 100KB or 200KB. You upload a perfectly fine-looking document, hit Submit, and get "File size exceeds the permitted limit". Minutes before the deadline, this is the most stressful error on Indian application forms.

Quick answer: Open the Compress PDF tool, drop your file, select the Extreme preset, tick the grayscale option if the document is a colour scan, and press Compress. A typical 2–4MB marksheet lands between 60KB and 150KB — comfortably under the 100KB mark.

Why does your PDF weigh so much in the first place?

Before compressing, it helps to understand where the weight comes from. Almost always it is one of these:

  • Scanned pages captured in colour. A phone scan of a marksheet stores full colour data for a page that is mostly white paper and black text. Colour scans are usually 3–8× heavier than the same page in grayscale.
  • Captured at high camera resolution. Modern phones shoot 12MP photos. Embedded into a PDF, a single page can become 1–3MB on its own.
  • Embedded fonts and metadata. Word and scanner apps embed complete font tables, colour profiles and hidden metadata that add weight nobody can see.
  • Images inside a document. Logos, stamps, scanned signatures and photographs all add up quickly.

Step-by-step: compress any PDF below 100KB

  1. Open the tool. Go to the Vytra Compress PDF page. Nothing installs and no account is needed — the file stays inside your browser.
  2. Drop your PDF into the file box. The page shows the current size so you know your starting point (for example, 4.2 MB).
  3. Choose the preset. Pick Extreme when a portal has a hard 100KB or 200KB limit. Stick with Recommended if you only need a lighter file for email or WhatsApp.
  4. For scanned documents, tick "Convert scanned marksheets to grayscale". This is the single biggest size lever for scans — it drops the colour channels while keeping text crisp.
  5. Name the output and press Compress PDF Now. Download the result and check the size before uploading to the portal.

Real example: A colour phone scan of a degree certificate started at 3.8 MB. Extreme preset + grayscale brought it to 96KB — under the 100KB limit in one attempt. The same file with only the Recommended preset stopped at 640KB, because light compression cannot overcome a colour scan.

Which preset should you actually pick?

  • Recommended — best balance of size and readability; start here for 95% of documents (emails, sharing, general uploads).
  • Extreme — smallest possible file for hard portal limits. Be honest about the trade-off: Extreme rasterises pages, which means text becomes an image — it can no longer be selected, searched or copy-pasted. For exam uploads nobody reads text digitally, so this is usually fine.
  • Low — light compression that strips metadata while keeping image fidelity. Use it when the file is slightly over a generous limit (say, 2MB) and quality matters most.
  • Grayscale checkbox — always combine with Extreme for scans, photographs of documents, and marksheet bundles.

Common problems and quick fixes

"The output is still above 100KB"

Check how many pages the PDF has. A 15-page document has far more image data than a single-page certificate. Options: split out only the pages the portal asks for (the Split PDF guide explains how), then compress that smaller file. Also confirm you actually selected Extreme — Recommended will not always cross the finish line.

"The text looks blurry after compressing"

Blur after compression means the preset went too aggressive for that particular file. Two fixes: switch to Recommended if the limit allows a slightly larger file, or re-scan the document at 150–200 DPI in grayscale first. A clean grayscale scan usually compresses small and stays sharp — blurry results almost always start as low-quality, over-compressed camera photos.

"The portal still rejects the file"

Some portals check more than size — page count, PDF version, or whether the PDF has a password. Confirm the limit is really about kilobytes, and make sure the file is not password-protected (portals cannot open encrypted PDFs; the password guide covers what to do).

Pro tips

  • Always compress before the last day of registration — you want time to verify readability.
  • Check the final size in your phone's file manager before uploading; don't trust your memory of the limit.
  • Keep the original large PDF safe. You will need it for later rounds, counselling and document verification.
  • One document, one file: portals usually reject a bundle that mixes several certificates unless the notification says otherwise.
  • For repeated forms, compress once and reuse the file across applications that share the same 100KB rule.

Frequently asked questions

Is compressing a PDF for an exam form allowed?
Yes. Portals publish size limits precisely because they expect you to compress or rescan documents to fit them. You are not altering the document's content — only its file size.
Will Extreme compression make my text unreadable?
On documents with clean, high-contrast scans, text stays perfectly readable to the eye — but it becomes an image, so selection and search stop working. If the portal limit allows, Recommended keeps text selectable.
Do I need to install any software?
No. The compression runs entirely in your browser. Your file is not uploaded to any server, which matters for marksheets, certificates and ID proofs.
How many PDFs can I compress at once?
Compress each document separately when a portal asks for individual uploads — that also gives you per-file control over the final size.
