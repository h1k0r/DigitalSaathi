Last Updated: October 2026 • Effective Date: October 2026

Welcome to Vytra (https://vytra.in/). We are dedicated to respecting and protecting the privacy of our visitors. This Privacy Policy describes how information is handled when you use our client-side tools and browse our website.

Core Guarantee: 100% In-Browser File Processing

When you use Vytra tools (such as PDF compression, image resizing, format conversion, password generation, or calculation), your documents, photographs, and inputs are processed exclusively on your device. We do not upload, transmit, store, or view your files on any remote server.

1. Information We Do Not Collect

Because Vytra operates as a static client-side web application hosted via GitHub Pages:

  • No File Storage: Your PDF files, images, code snippets, tokens, and documents are never uploaded to any server. File handling uses HTML5 File API, WebAssembly, and Canvas within your browser sandbox.
  • No Account Creation: Vytra does not require user registration, usernames, or passwords to access any tool.
  • No Financial Data Collection: Our financial and academic calculators (such as Loan EMI, CGPA, Attendance) compute values strictly in local JavaScript memory. No financial figures are logged or recorded.
