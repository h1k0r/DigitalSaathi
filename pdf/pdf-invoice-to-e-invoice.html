Frequently Asked Questions

How does the PDF to electronic invoice conversion work?

When you load a PDF invoice, our tool uses Mozilla's PDF.js library to inspect the document's text layers. It analyzes patterns, regular expressions, and layout positions to identify the invoice number, tax registration IDs, dates, and amounts. It then structures this data into standard ZUGFeRD, UBL, or GST e-invoice formats.

Will scanned PDF invoices (images) work?

The converter works best with digitally generated PDFs that contain selectable text layers. If you have a scanned picture or flattened image invoice, you can either run optical character recognition (OCR) first or simply load the PDF and manually verify and populate the fields in the editable review panel.

Can I review and edit the data before generating the electronic file?

Yes, absolutely. The interface displays an editable review form on the left where you can modify the invoice number, dates, company names, VAT IDs, and amounts. Every change updates the generated XML or JSON output in real time.

Are my confidential commercial invoices uploaded to your servers?

No. The entire process runs locally inside your browser's execution memory. The PDF file is never uploaded to any remote server or stored in any cloud database.

Which accounting software can import these electronic files?

The generated XML and JSON conform strictly to European EN 16931 and Indian NIC specifications. They are natively compatible with DATEV, Lexware, SAP Business One, Oracle NetSuite, TallyPrime, and Peppol-enabled electronic document exchange systems.

Is this tool free for corporate and commercial use?

Yes, completely free. There are no monthly conversion quotas, signups, or subscription fees.
