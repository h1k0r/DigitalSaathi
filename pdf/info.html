Frequently Asked Questions

What information does PDF metadata contain?
PDF metadata includes internal document properties such as the Title, Author name, Subject, Keywords, Creator software (e.g., Microsoft Word, Canva, InDesign), PDF specification version, and original creation and modification timestamps.
Can I remove or strip author and creator metadata for privacy?
Yes! Click the ' Clear Metadata (Anonymize)' button. This wipes the Author, Subject, Keywords, and Title fields clean before downloading, ensuring your identity or organization name remains anonymous when publishing public files.
Does inspecting or editing metadata alter document text or formatting?
No. Metadata is stored in a dedicated Info dictionary object inside the PDF container. Modifying these text fields does not re-render or alter the content streams, text layouts, or embedded images of the actual pages.
Are my confidential files uploaded or saved on any server?
Never. All inspection and metadata editing happen 100% locally in your device RAM using PDF-Lib. Your files never touch an external server.
