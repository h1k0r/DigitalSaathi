Frequently Asked Questions

What XML invoice formats are supported?

Our tool parses UN/CEFACT Cross Industry Invoice (CII) XML (used by ZUGFeRD 2.2 and French Factur-X), German XRechnung, OASIS Universal Business Language (UBL 2.1), and Indian Goods and Services Tax NIC Schema v1.03 JSON files.

Can I edit the electronic invoice before generating the PDF?

Yes. The Electronic Source Code editor on the left allows you to edit XML tags, quantities, prices, or names directly. The visual invoice preview updates automatically in real-time.

Is my electronic invoice data uploaded to any server?

No. Everything runs 100% inside your browser's local sandbox memory using standard JavaScript DOMParser and jsPDF. No document or data is ever sent across the network.

How do I print the converted invoice?

You can either click the "Print" button to send the rendered A4 invoice directly to your office printer, or click "Download PDF" to save a high-resolution vector PDF file to your computer.

What if my XML file has formatting errors or syntax issues?

Our built-in XML parser detects syntax and missing node errors, alerting you if tags are improperly closed so you can make quick corrections or validate the file using our Validate E-Invoice tool.

Is this tool free for corporate and commercial use?

Yes, 100% free with unlimited conversions, zero subscriptions, and no forced watermarks.
