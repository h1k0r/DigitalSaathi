When to compress a PDF with Vytra Compress

Almost every government and banking portal caps uploads — 100 KB, 200 KB, 1 MB. Vytra Compress reduces a PDF inside your browser with three presets: Light for files that are close to the limit, Balanced for ordinary documents, and Extreme for scanned files that are far over. The grayscale toggle helps most with scanned marksheets and handwritten papers, where colour adds size but no information. The live size readout updates as you change presets, so you can stop as soon as the file drops under the portal's cap.

Compression works by re-encoding the images inside the PDF at lower resolution while keeping the text layer intact, which is why scanned documents shrink far more than text documents. If a file barely moves, it is already near the minimum for its content — reduce the pages themselves with Split instead of pushing quality lower. You can switch presets and preview repeatedly; the original file on your device is never modified until you save the copy.

Common problems and how to fix them

  • Barely any reduction — the file is probably text-based and already near its minimum; try Extreme, then grayscale.
  • A scanned document stays large — scans are images; grayscale plus Extreme usually cuts them by 60-80%.
  • Output looks blurry — use Light instead of Extreme when the document must stay clearly readable.
  • Still over the limit — extract only the required pages with Split first, then compress.

A quick example

A 2.1 MB scanned marksheet must go under 200 KB. Choose Extreme, tick grayscale, wait for the readout to settle under 200 KB, save, and confirm the size in your file manager before uploading.

If the portal rejects the file again afterwards, read its instruction page once more — some forms cap page count as well as size, and the fix then is Split, not a lower preset.
