Frequently Asked Questions

What is a PDF Workflow Pipeline and how does it work?

A PDF Workflow Pipeline allows you to chain multiple document modification tasks—such as stamping page numbers, applying text watermarks, adjusting page rotation, flattening interactive forms, and purging metadata—into an automated sequence. Instead of uploading and downloading files across 4 different websites, everything happens in one fast step.

Is my confidential PDF uploaded to any external server?

No. All document processing takes place directly in your web browser's RAM memory using WebAssembly PDF-lib. Neither your source PDF nor the processed output is ever transmitted to or stored on any server.

What is AcroForm flattening and why is it useful?

Form flattening converts interactive fillable text boxes, radio buttons, and digital signatures into permanent, immutable vector background graphics. This prevents recipients from tampering with filled data and ensures identical appearance across all PDF viewers and printers.

Why should I sanitize metadata before sharing a PDF?

PDF files often store hidden metadata containing author names, company titles, computer file paths, creation timestamps, and software versions. Sanitizing metadata wipes these footprints clean to safeguard privacy and confidentiality.

Can I customize the watermark text and opacity?

Yes! You can enter custom text (such as "CONFIDENTIAL", "DRAFT", or your company name), choose between diagonal 45° or horizontal orientation, and adjust opacity from subtle 15% gray to high-visibility 40% red.

Does this tool work on mobile phones (Android / iOS)?

Yes, Vytra is fully mobile-responsive and functions smoothly on iPhone Safari, Android Chrome, iPads, and laptops without installing any apps.
