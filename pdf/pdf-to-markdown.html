Frequently Asked Questions

Everything you need to know about converting PDFs to clean Markdown on Vytra.

Why is Markdown format better than raw PDF text for ChatGPT and LLMs? +
Large Language Models (LLMs) like GPT-4, Claude 3.5, and DeepSeek are pre-trained extensively on GitHub repositories, documentation sites, and structured Markdown. When you supply Markdown with clear headings (#, ##, ###) and lists, the attention heads of the model maintain accurate hierarchy. In contrast, raw PDF extraction often contains mid-sentence line breaks, repeated running headers, and orphaned page numbers that confuse prompt processing.
How does the converter identify H1, H2, and H3 headers? +
PDF.js extracts the typographic transformation matrix and font height of every text element. Our client-side heuristic engine calculates the median body font size of the document. Any text that exceeds the median height by defined thresholds is tagged as H1, H2, or H3, giving you a semantic document outline automatically.
Can I import the generated .md file directly into Obsidian or Notion? +
Yes. The generated Markdown conforms to standard CommonMark and GitHub Flavored Markdown (GFM) standards. You can download the .md file and drag it straight into your Obsidian vault, Notion workspace, Roam Research, Logseq, or a Git repository.
Is my data uploaded to any server or shared with AI providers? +
No. The entire conversion process occurs locally inside your web browser. Neither your original PDF nor the converted Markdown text is transmitted to any cloud server or third-party AI provider.
How are page numbers and boundaries handled? +
You can configure page markers to appear as clean comments (<! - Page X - >), secondary headers (## Page X), horizontal dividers ( - ), or omit them entirely to create a seamless continuous document stream.
Is there any document page or file size limit? +
No artificial limits exist. You can convert 1-page cheatsheets or 400-page programming manuals directly on your computer without subscription paywalls or rate limits.
