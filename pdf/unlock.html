Questions and Answers

Can I unlock an e-Aadhaar card PDF?
Yes. Upload your e-Aadhaar PDF and enter the standard UIDAI password (first four letters of your name in CAPITAL LETTERS followed by your 4-digit birth year, e.g. SURE1995). Vytra saves a completely unlocked version that will never ask for a password again.
Do I need to enter the password?
If your document has an open password, you need to enter it once so that the browser can decrypt the file. If the file only has permissions restrictions (like copy or print disabled), no password is needed.
Is my password or file saved on any server?
No. All decryption runs locally on your computer or phone using HTML5 and JavaScript. Nothing is sent to our servers.
Can I lock the file again later?
Yes! You can use our Protect PDF tool anytime to add a new password and restrict permissions.
