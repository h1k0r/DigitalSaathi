Frequently Asked Questions

What is an electronic invoice (e-invoice)?

An electronic invoice is a structured data document issued, transmitted, and received in a specified machine-readable electronic format (such as XML or JSON). Unlike a static PDF or scanned piece of paper, an e-invoice can be automatically ingested and processed by receiving ERP and accounting systems without manual data entry.

What is the difference between ZUGFeRD 2.2, Factur-X, and UBL 2.1?

ZUGFeRD 2.2 (Germany) and Factur-X (France) are identical specifications based on the UN/CEFACT Cross Industry Invoice (CII) standard, designed primarily as hybrid invoices (an XML file embedded inside a PDF/A-3 document). UBL 2.1 (Universal Business Language) is an OASIS XML standard widely adopted by the European Peppol network. Both standards fully comply with European Norm EN 16931.

How does Indian GST e-Invoicing work?

In India, registered GST businesses with turnover exceeding statutory thresholds must upload invoice JSON payloads to the government Invoice Registration Portal (IRP). The IRP validates the payload and returns an Invoice Reference Number (IRN) and a digitally signed QR code. Vytra creates the compliant JSON payload according to NIC Schema v1.03 for direct upload or API testing.

Is my financial data uploaded to any server?

No. All XML string serialization, JSON formatting, mathematical calculations, and PDF generation execute 100% locally inside your web browser's JavaScript sandbox. No financial information, bank accounts, or customer records ever leave your device.

Can I embed this XML into a PDF file to make a hybrid invoice?

Yes. You can download the generated XML and use our companion tool XML E-Invoice to PDF or standard PDF tools to combine them into an EN 16931-compliant PDF/A-3 hybrid electronic invoice.
