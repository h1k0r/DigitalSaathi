Frequently Asked Questions

Can someone remove the black redaction boxes to reveal the hidden text? +
No. When using Vytra Permanent Redaction, the blacked-out areas are baked directly into the document stream or flattened into high-resolution non-selectable raster layers. Unlike simple drawing overlays, the underlying vector text and characters are permanently sanitized and impossible to recover via copy-paste or PDF inspection tools.
Is this tool suitable for creating Masked Aadhaar cards? +
Yes. According to UIDAI and RBI KYC guidelines, only the last 4 digits of the Aadhaar number should be visible when submitting ID proofs for non-statutory purposes. You can easily draw a solid blackout box over the first 8 digits and the QR code to create a fully compliant Masked Aadhaar PDF.
Do my sensitive documents or ID cards ever upload to an external server? +
No. 100% of the redaction and PDF processing executes client-side inside your browser memory using HTML5 Canvas and WebAssembly. Your confidential Aadhaar cards, bank statements, and tax returns never touch any remote server, guaranteeing absolute data privacy.
Can I redact multiple pages of the same PDF document? +
Yes. Use the page navigation bar above the preview to move between pages. You can draw redactions across multiple pages throughout the document; all marked areas will be sanitized simultaneously upon download.
What is the difference between solid blackout and whiteout? +
Solid blackout covers the text with an opaque #000000 black box (standard for government, legal, and financial redactions to clearly signal that data has been removed). Solid whiteout applies an opaque #ffffff white box, seamlessly blending into white document backgrounds for a clean erased appearance.
