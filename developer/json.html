Frequently Asked Questions

Why does JSON reject single quotes?
The official JSON specification (ECMA-404 and RFC 8259) was intentionally designed as a strict, universal data interchange format. Requiring double quotes for all strings and object keys ensures cross-compatibility across all programming languages (C++, Java, Python, Go, Rust, and PHP) without ambiguous quote escaping.
How do I fix 'Unexpected token' syntax errors in JSON?
'Unexpected token' errors are usually caused by: 1) Trailing commas at the end of an array or object, 2) Keys missing double quotes, 3) Unescaped special characters (e.g. unescaped newlines or quotes inside a string), or 4) Using undefined or Python keywords like True, False, or None instead of true, false, and null.
What is the difference between Formatted and Minified JSON?
Formatted JSON includes indentations (spaces or tabs) and line breaks to make it simple for human developers to read and inspect. Minified JSON strips all non-essential whitespace, reducing file size and bandwidth consumption during network requests.
Is my private data uploaded to external servers?
Never. All parsing, validation, formatting, and tree rendering take place entirely client-side inside your browser. No data, payloads, or file uploads are ever transferred to or saved on Vytra servers.
