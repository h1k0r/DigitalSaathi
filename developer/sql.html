Frequently Asked Questions

Why should SQL keywords be written in uppercase?
Writing SQL reserved keywords (like SELECT, FROM, WHERE, JOIN) in uppercase is the recognized industry standard. It creates clear visual contrast between native language commands and application-specific table and column identifiers.
Does this formatter work with MySQL and PostgreSQL queries?
Yes! It works universally across MySQL, PostgreSQL, SQLite, Oracle, Microsoft SQL Server, and MariaDB queries without requiring dialect-specific plugins.
Are my confidential database queries sent to external servers?
No. All formatting and syntax highlighting occur 100% locally within your web browser using client-side JavaScript. No query text or database schema information is ever uploaded or logged.
Can I format DDL statements like CREATE TABLE?
Yes, DDL commands (CREATE TABLE, ALTER TABLE, DROP TABLE, CREATE INDEX) as well as DML commands (INSERT, UPDATE, DELETE) and complex DQL queries are fully supported.
