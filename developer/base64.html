Base64 Encoding FAQ

What is Base64 Encoding?

Base64 is a binary-to-text encoding scheme that translates binary data (like images or bytes) into an ASCII string format suitable for HTML, CSS, and API transmission.

Are my files uploaded to your servers?

No. All Base64 conversions occur 100% in your local browser using the JavaScript FileReader API.
