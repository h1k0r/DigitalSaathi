Frequently Asked Questions

What is Base64 encoding used for?
Base64 is used to convert binary data (like images, PDF files, or encrypted keys) into an ASCII string format. This allows binary media to be transmitted safely over media channels designed strictly for text, such as HTTP headers, HTML/CSS code, XML, and SMTP emails.
Why does Base64 increase data size by ~33%?
Base64 encodes every 3 bytes (24 bits) into 4 characters (each representing 6 bits). Because 4 bytes are used to transmit what originally took 3 bytes, the payload size expands mathematically by 4/3, or approximately 33.3%.
Is Base64 considered encryption?
No. Base64 is an encoding scheme, not an encryption method. It uses no cryptographic key and can be instantly reversed by anyone. Never use Base64 alone to protect passwords or confidential information.
Are my files or strings stored on Vytra servers?
No. All encoding, decoding, and file conversions occur 100% locally within your web browser using HTML5 FileReader and TextEncoder APIs. No data or files are ever sent to our servers.
