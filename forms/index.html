Form-Ready Kit for Indian applicants

Generic file tools stop at "we edited your file". Form portals ask a follow-up question: does this file follow the rules? The Form-Ready Kit answers it — every tool here knows the KB bands, pixel sizes and formats that SSC, IBPS, RRB and UPSC portals actually validate, compiled from official notifications with sources.

Pre-flight Checker

Verify photo, signature or PDF against your exam's rules: KB band, pixels, format, background, encryption, page count — with plain-language reasons and one-click auto-fix.

Exam-specific guides (with the tool pre-set)

Each guide below opens the right tool with that exam's preset already active, shows the official spec table with sources, and fixes the rejections its candidates actually see:

  • SSC photo resize (20–50 KB, exact pixels)
  • IBPS signature resize (10–20 KB)
  • RRB photo & signature size guide
  • Compress PDF to under 100 KB
  • Compress PDF to under 200 KB

The workflow this kit assumes

  1. Read the notification's instruction page once — note KB bands and pixel asks.
  2. Resize photo and signature with the matching presets (or manual numbers).
  3. Run the Pre-flight Checker on every file the night before the deadline.
  4. Upload the ✅ files with confidence — and keep originals untouched for the next form.
Exam limits change between notifications. This kit's numbers are compiled with sources and dates — but the instruction page of the live form is always the final authority. When they disagree, the form wins.

Everything runs in your browser: no accounts, no queues, no files on a server. The privacy badge on each tool counts file-upload requests since page load — it stays at zero because nothing here has anywhere to upload to.
